# Photo Gallery Setup

Because your website is statically hosted on GitHub Pages, it cannot automatically read how many files you have placed in this folder. Instead, the website is programmed to look for exactly **12** photos with specific names.

### How to add photos to the gallery:

1. Gather up to 12 of your favorite photos.
2. Convert them to `.jpg` format.
3. Name them exactly as numbered files starting from 1:
   - `1.jpg`
   - `2.jpg`
   - `3.jpg`
   - ... up to `12.jpg`
4. Drag and drop them into this `photos` folder in your GitHub repository and commit the changes!

**Note:** You do not have to upload all 12. If you only upload `1.jpg` through `6.jpg`, the website will simply ignore the missing ones and only display your 6 photos perfectly in the grid.

### Aspect Ratio Tip:
The gallery grid is designed to look best with portrait-oriented photos (4:5 ratio, similar to Instagram). Wide photos will be automatically cropped from the center to fit the elegant grid perfectly.
